Repositorio:
Un repositorio es el espacio donde se guardan todos los archivos y cambios de un proyecto. 
Funciona como una carpeta inteligente que permite organizar el trabajo y llevar un control de las diferentes versiones. 
Puede estar en el computador o en plataformas en línea como GitHub.

Commit:
Un commit es una forma de guardar los cambios realizados en un proyecto dentro de Git. 
Cada commit crea un punto de control que ayuda a mantener el orden y facilita recuperar versiones anteriores si es necesario. 
Normalmente se acompaña de un mensaje corto que explica qué se modificó.

Push:
Push es el proceso de enviar los cambios guardados en el computador hacia un repositorio remoto. 
Este comando permite actualizar proyectos en GitHub y compartir el trabajo con otras personas o equipos. 
Por lo general, se utiliza después de hacer uno o varios commits.
