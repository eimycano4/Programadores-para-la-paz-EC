Sistema operativo:
Es el software principal que administra los recursos del computador.
Permite que el servidor funcione y que las aplicaciones puedan ejecutarse correctamente.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador.
Se utiliza para crear y ejecutar aplicaciones del lado del servidor.

Aplicación server.js:
Es el archivo que contiene la lógica principal del servidor
Se encarga de procesar solicitudes y enviar respuestas a los usuarios.

Puerto:
Es un punto de comunicación que permite al servidor recibir conexiones.
Cada aplicación utiliza un puerto específico para atender solicitudes.

Logs:
Son registros que almacenan eventos y actividades del servidor.
Ayudan a monitorear el funcionamiento y a detectar errores o problemas.
